# Scanner images and sounds

Original transparent 40 × 40 PNG icons and mono 16 kHz PCM sound cues.

| Asset | Used for |
| --- | --- |
| shield.png | App window and title |
| priority.png | High-priority findings |
| added.png | Added entries |
| changed.png | Changed entries |
| absent.png | Absent entries |
| remote.png | Remote access |
| coverage.png | Incomplete checks |
| complete.wav | Successful scan without high-priority findings |
| attention.wav | Completed scan with high-priority findings or processes |
| error.wav | Collection failure |

Enable Scan sounds on Overview. Cancellation and opening saved scans are silent.
