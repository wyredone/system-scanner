Quick Start

  1. Run a scan on your PC and open Startup & Tasks.
  2. Save a named baseline snapshot. Scan again after a software install or other change.
  3. Choose the baseline under Before and Current under After. Select an Added or Changed row to compare its evidence.
  4. Use Explain for an advisory local Ollama explanation. Use Hash lookup if you want to send the file hash to VirusTotal.
  5. For a confirmed unwanted live task, select Disable and review the prompt. The automatic rescan shows the new state.

Startup and scheduled-task snapshots

The workspace includes scanned Registry Run entries, Startup folder items, and scheduled task actions. Before and After accept a saved scan from the list or a full snapshot path. Compare snapshots collected from the same PC. Scan coverage and permissions can affect whether an entry appears.

A task can have multiple actions. A TaskDigest change indicates that its exported definition changed. Saved snapshots contain scan details and can include private paths, commands and task definitions.

Disable, delete, restore, and block

Actions to change Windows apply to selected live scheduled tasks and supported Registry Run entries. Take a new full scan first. Permissions depend on the task. If Windows denies access, use Run as admin and scan again. The scanner checks that the complete task definition still matches the scan before acting.

Disable is reversible with Enable. Delete writes the task definition to scans/task-backups first. Restore task reads a trusted backup and registers the saved task only when the destination is vacant. A restored task can run automatically. Tasks that require a password or depend on accounts, programs, or folders unavailable on this PC may need Windows Task Scheduler.

Block / Unblock disables a live scheduled task when necessary and saves a watch for that entry. For standard Registry Run and RunOnce entries, it removes the value after saving a backup and adds a watch. Restore Run entry re-creates the backed-up value if the slot is vacant. Startup folder items support watches. A later scan shows Block alert if the watched entry is present and not verified disabled. Unblock removes the watch. Use Enable separately for a disabled task. Watches run at scan time and do not prevent executables from launching.

Settings backup and restore

Open Settings backup from Overview. Export settings saves a versioned JSON file with the model choice, review notes, and block watches. Review notes and rule names may contain information you entered or identifiers from the scan.

Import settings shows additions and replacements before applying the backup. Merge keeps local keys that the backup does not replace. Replace loads the backup as your saved settings. The current settings are backed up under scans before either operation. Imported watches are scan-time rules. Open Ollama settings and use Test connection to verify that the preferred model exists on this PC.

Run a scan

  1. Extract the project folder and install Python 3 with Tkinter.
  2. Double-click Scan Computer.bat. The scan starts when the app opens.
  3. For greater visibility, use Scan Computer (Admin).bat and accept the Windows prompt.

Click the ? buttons beside controls for help. A scan can miss entries because of permissions or collection errors.

Review first. A heuristic may flag legitimate software.
Medium
Verify software and activity you do not recognize.

Review incidental issues such as startup entries pointing to missing files.

Inventory and scan context. Tick Info to show these rows.

Select a row to read its recorded evidence. Check hash on VirusTotal opens a separate browser lookup for the file hash.

Explain a finding with local Ollama

  1. Install and start Ollama on the same Windows PC. Confirm it is running on the default local port, 11434.
  2. Use the default model by running this in a terminal: 
    ollama pull llama3.1:8b
  3. Select a row in Persistence Findings or Running Processes, then click Explain This Finding.

To use another installed local model, set the SCANNER_OLLAMA_MODEL environment variable to the exact tag from ollama list, then relaunch the scanner.

The scanner sends severity, signature information, and matching rule reasons to the loopback Ollama endpoint. Review the generated explanation against the raw evidence. The explanation cannot change severity or perform actions.

If the app cannot reach Ollama, start the service and try again. If the model is missing, install it or check the configured tag. Model loading and generation may take longer on the first request.

Review and stop a running process

Use a fresh scan. Open Running Processes and review the selected process, PID, executable path, and related entries. Stop Selected Process force-stops one eligible process after confirmation. Save your work before proceeding. The app checks the process identity again and records the result in scans/process-actions.jsonl.

Saved scans are view-only. A service or scheduled task may restart a stopped process.

Compare and export reports

Reports are saved under scans. New or changed shows entries with a new category, name, path, or command combination. The comparison also checks the file hash, signature, service or task state, and remote-session count and time. Coverage rows show section-level collection errors. Optional Windows components can be absent.

Use Export report (HTML) for browser viewing or Export CSV for spreadsheets. Review exported reports for private information before sharing.

Review a scan from Overview

Select a count to open matching records. The comparison filter shows added, changed, or absent entries. A changed entry includes its prior evidence. Keep a local review note from the findings toolbar. A different command, signature, hash, or tracked state calls for a fresh review.

Network shows listening and established TCP endpoints and bound UDP endpoints. Process ownership comes from the scan snapshot. Remote Access combines local log records, detected tools, running processes, and the AnyDesk unattended-access indicator.

Ollama settings lists installed local models. Explain scan sends a bounded set of finding summaries to the selected model. Use the evidence selector to open cited findings.

Redacted export previews an inventory by severity and category. Names, paths, addresses, arguments, and free text are omitted. Cancel ends an in-progress collection. Retry failed checks refreshes incomplete sections and any required process or service data. The resulting scan also contains records from the original collection.
